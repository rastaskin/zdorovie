# Макеты для Figma

Экраны приложения в SVG: ПК (1280 px) и iPhone (390 px), 8 экранов. Данные выдуманные: пациент «Иван Образцов».

## Как открыть в Figma

1. Создайте файл в Figma.
2. Перетащите SVG из `design/figma/` на холст. Можно все сразу: каждый станет отдельным фреймом.
3. Шрифты **Kurale**, **Alegreya Sans SC** и **Marck Script** есть в Figma среди Google Fonts, ставить ничего не нужно.

Что можно править: тексты — это текстовые слои, плашки, рамки и кнопки — это прямоугольники, всё можно двигать. Фактуры (дерево, пергамент, узор панели), гербы и значки — картинки. Внутреннее затенение по краям в макеты не переносится.

PNG рядом с каждым SVG — снимок живого приложения для сверки.

## Как вернуть правки

Экспортируйте изменённые фреймы в PNG (или пришлите ссылку на файл Figma) и коротко напишите, что поменяли и зачем.

## Пересобрать макеты

```
node design/export.mjs
```

Нужен Microsoft Edge (по умолчанию) или `PW_CHANNEL=chromium` с установленным Playwright Chromium. Результат — в `design/figma/`, папка в git не попадает.
