# Здоровье: установка и синхронизация

## iPhone

1. Откройте в Safari https://rastaskin.github.io/zdorovie/
2. «Поделиться» → «На экран „Домой“». Дальше открывайте только с этой иконки: у вкладки Safari отдельное хранилище.

## ПК (Windows)

1. Откройте https://github.com/rastaskin/zdorovie/releases/latest и скачайте `Zdorovie_…_x64-setup.exe`.
2. Запустите. Windows покажет «Windows защитила ваш компьютер»: установщик не подписан платным сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».
3. Обновления приходят сами: при запуске появится «Доступна версия …» → «Обновить».

## Синхронизация через Google Drive

На устройстве, где медкарта уже есть (обычно iPhone):
1. «Данные» → «Подключить Google Drive» → войдите в Google и разрешите доступ.
2. Откройте медкарту фразой или Face ID. В шапке появится «Синхронизировано …».

На втором устройстве (ПК):
1. На первом экране: «Подключить медкарту из Google Drive» → войдите в тот же аккаунт Google.
2. Введите кодовую фразу медкарты. Готово: дальше отметки расходятся сами в течение минуты.

Что попадает в Google: только зашифрованный файл в скрытой папке приложения. В интерфейсе Drive его не видно, без фразы его не прочитать.

## Если что-то не так

| В шапке | Что делать |
|---|---|
| «Нет связи с Google» | Проверьте интернет. Синхронизация повторится сама, когда сеть появится. Данные сохраняются на устройстве |
| «Войти в Google» | Нажмите на надпись и войдите заново. В режиме Testing Google иногда просит вход раз в неделю. На iPhone после входа медкарту нужно открыть ещё раз |
| «В Google Drive другая медкарта» | В облаке медкарта с другой фразой (например, создали новое хранилище вместо подключения). «Данные» → введите фразу облачной медкарты → «Подключиться». Данные с этого устройства добавятся в неё, Face ID включите заново |
| «Ошибка синхронизации» | Нажмите на надпись, чтобы повторить. Если не проходит, сохраните резервную копию («Данные» → «Сохранить копию») и напишите Claude |

Сменили фразу на одном устройстве — второе примет новую при следующей синхронизации. Открывать его дальше нужно новой фразой.
